# Yeamin Sheikh

Software developer based in Bangladesh. I write automation tools, browser extensions, and CLI programs for Windows. Most of my day-to-day code is in Python, TypeScript, and C#.

---

### What I build

- [dola-extension](https://github.com/Yeamin-Sheikh/dola-extension)
  Chrome extension that strips watermarks and handles batch downloads on the Dola AI video platform.

- [yeaprompts](https://github.com/Yeamin-Sheikh/yeaprompts)
  Offline prompt database and web UI storing 279 tested video prompts with instant search and SQLite storage.

- [yt-adjust](https://github.com/Yeamin-Sheikh/yt-adjust)
  Chrome extension for YouTube that adds mouse-wheel volume controls, volume boost, picture-in-picture, and automatic sponsor skipping.

- [Audify](https://github.com/Yeamin-Sheikh/Audify)
  Windows system tray app that reads clipboard text out loud using Microsoft Edge neural text-to-speech voices.

- [windows-cloud-sandbox](https://github.com/Yeamin-Sheikh/windows-cloud-sandbox)
  GitHub Actions workflow that spins up a disposable Windows cloud runner with Remote Desktop and Tailscale networking.

- [csharp-fundamentals](https://github.com/Yeamin-Sheikh/csharp-fundamentals)
  Clean collection of introductory C# console projects covering terminal I/O, error handling, and basic algorithms.
